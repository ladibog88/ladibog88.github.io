DumplingThoughts

Family Second Brain — React Web App + Telegram Bot

What started as a personal Telegram bot to capture thoughts evolved into a full-stack web app — built so my parents could use it too. Users can add, browse, and complete entries across 9 categories, backed by Google Sheets as the database and designed with senior accessibility front of mind.

React 19 TypeScript Node.js / Express Google Sheets API Tailwind CSS v4 Python Telegram Bot API Railway

The Problem

On sabbatical, my thoughts lived everywhere — ideas in Telegram messages to myself, Thai vocabulary disappearing into the notes app, to-dos spread across three tools, links buried in browser tabs. I had no single place where everything lived, and no way to look back at how my thinking had evolved over time.

I needed a second brain. So I built one — starting with a Telegram bot for fast capture, then realising the people I most wanted to share it with (my parents) were never going to use Telegram for this.

That's what pushed it to v2: a proper web app the whole family could open, navigate, and use independently — without me having to explain anything.

The App
