DumplingThoughts

Family Second Brain — React Web App + Telegram Bot

What started as a personal Telegram bot to capture thoughts evolved into a full-stack family web app — built so my parents could use it too. A PIN-authenticated React dashboard lets the whole family add, browse, and complete entries across 9 categories, backed by Google Sheets as the database and designed with senior accessibility front of mind.

React 19 TypeScript Node.js / Express Google Sheets API Tailwind CSS v4 Python Telegram Bot API Railway

The Problem

On sabbatical, my thoughts lived everywhere — ideas in Telegram messages to myself, Thai vocabulary disappearing into the notes app, to-dos spread across three tools, links buried in browser tabs. I had no single place where everything lived, and no way to look back at how my thinking had evolved over time.

I needed a second brain. So I built one — starting with a Telegram bot for fast capture, then realising the people I most wanted to share it with (my parents) were never going to use Telegram for this.

That's what pushed it to v2: a proper web app the whole family could open, navigate, and use independently — without me having to explain anything.

What I Learned

👨‍👩‍👧

Build for Your Real Users, Not Yourself

The Telegram bot worked perfectly for me — and was completely inaccessible to my parents. Rebuilding as a web app forced me to think about tap target sizes, contrast, discoverable interactions, and reducing cognitive load for people who didn't grow up with smartphones.

🔐

Secrets Management — The Hard Way

Accidentally pushed API keys to a public GitHub repo early on. Immediately revoked everything, scrubbed the git history, and rebuilt security practices from scratch. Cloud platforms like Railway also mangle private keys in subtle ways — stripping quotes, breaking newlines — that only surface in production.

🌐

The Browser Can't Touch Google Sheets Directly

A key architectural decision: the Google Sheets API requires a service account private key, which can never be in client-side code. This pushed me to build a proper Express backend — not just a thin proxy, but a real authenticated API layer with JWT sessions.

🏗

V1 Made V2 Possible

Having real data flowing into Google Sheets from day one — via the Telegram bot — meant the web app had something meaningful to display the moment it launched. Shipping something simple first de-risked the whole project.

⚙️

Framework Gotchas Are Everywhere

Express 5 changed wildcard route syntax. Tailwind v4 moved to a CSS-first config. Railway encodes environment variables differently than local .env files. Each one cost debugging time — and taught me to read changelogs before upgrading.
